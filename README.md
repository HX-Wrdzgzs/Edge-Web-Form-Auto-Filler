

# Edge Web Form Auto-Filler / 网页表单批量自动勾选工具

这是一个基于 **Selenium** 开发的半自动化网页表单填写脚本。它专为特定教评、问卷或测试系统设计，能够自动识别页面中的单选框（Radio）与下拉菜单（Select），并批量将其勾选为 **"A"**（或优秀/非常满意）选项。

为了兼顾安全性和灵活性，脚本采用了“人工登录 + 自动填写 + 人工审核提交”的半自动化工作流。

---

## ## 功能特性

* **安全半自动设计**：将最敏感的“登录”和“提交”环节留给人工操作，有效避开验证码及前端防作弊检测，防止误提交。
* **动态 URL 监听**：内置 300 秒长等待机制，自动监控浏览器状态，一旦人工登录成功并跳转至目标页面（如 `main.aspx`），立即触发自动化填写。
* **智能分组与兜底**：
* **单选框**：自动按 HTML 的 `name` 属性对选项进行物理分组，优先寻找 `value="A"` 的选项；若找不到，则默认勾选该组第一项。
* **下拉菜单**：同时支持对 `value` 属性或标签文本（Text）进行 "A" 值的模糊匹配。


* **穿透点击驱动**：通过 JavaScript 注入（`arguments[0].click()`）驱动点击，能有效绕过由于页面动画、元素重叠或响应式布局引发的常规点击拦截错误。

---

## ## 前置准备

在运行脚本之前，请确保你的开发环境满足以下条件：

1. **Python 3.x** 已安装。
2. **Microsoft Edge** 浏览器已安装。
3. 安装依赖库 **Selenium**：
```bash
pip install selenium

```



> **注意**：现代版本的 Selenium 会自动管理和下载匹配的 `EdgeWebDriver`（驱动）。如果运行中提示驱动错误，请确保你的 Edge 浏览器升级到最新版，或手动下载对应版本的 WebDriver 并配置到系统环境变量中。

---

## ## 使用步骤

1. **配置目标地址**：
打开 `auto_fill_edge.py`，将 `main()` 函数中的 `url` 修改为你需要登录的初始系统网址：
```python
url = "http://202.111.48.235:18082/A05pjpx/" # 替换为你的目标网址

```


2. **执行脚本**：
在终端或命令行中运行脚本：
```bash
python auto_fill_edge.py

```


3. **人工辅助**：
* 脚本会自动启动一个 Edge 浏览器并打开配置的网址。
* **请在 300 秒内，在弹出的浏览器窗口中手动完成登录操作**。
* 登录成功并进入系统主表单页面（URL 包含 `main.aspx`）后，脚本会自动接管并执行批量勾选。


4. **审核与提交**：
* 脚本运行完毕后，会在终端提示 `所有选项已尝试设为 A。请检查无误后自行点击提交。`。
* 在网页上仔细核对填写结果，确认无误后**手动点击网页上的提交按钮**。
* 回到终端按下回车键，脚本将安全关闭浏览器并退出。

## ## 常见问题与二次开发提示

> [!IMPORTANT]
> **1. 脚本运行了，但是页面上的选项没有被勾选？**
> * **原因 A（Value 不匹配）**：很多系统的 A 选项在 HTML 源码中的 `value` 并不是 `"A"`，而是数字（如 `value="1"` 代表优秀）。此时脚本会默认勾选每题的第一项。如果第一项不是 A，需要修改脚本中 `value.upper() == 'A'` 的判断逻辑。
> * **原因 B（存在 Iframe 框架）**：很多旧版的 `.aspx` 系统喜欢使用 `<iframe>` 嵌套实际的内容页。如果页面存在框架，驱动将无法直接获取元素。你需要在执行选择逻辑前，加入一行切换代码：`driver.switch_to.frame(0)`。
