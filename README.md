# Edge Web Form Auto-Filler / 网页表单批量辅助填写工具

这是一个基于 **Selenium** 的 Edge 浏览器表单辅助脚本，用于处理重复性网页表单中的单选框与下拉菜单选择。脚本采用“人工登录、自动预填、人工复核、人工提交”的半自动流程，避免在未确认页面状态的情况下直接提交内容。

> 使用前请确认目标系统允许自动化辅助操作。本项目只适合个人学习、测试环境或明确允许自动化的内部流程；不要用于绕过平台规则、验证码、风控或考试/评价等必须由本人独立完成的场景。

## 功能特性

- **半自动流程**：登录和最终提交均由人工完成，脚本只负责在目标页面预填选项。
- **URL 等待**：启动 Edge 后等待用户完成登录，并在 URL 进入目标页面后继续执行。
- **单选框分组**：按 `name` 属性归类单选框，优先选择 `value="A"` 的选项，找不到时回退到该组第一项。
- **下拉菜单处理**：支持按选项 `value` 或文本内容匹配 `A`。
- **人工复核**：脚本执行后保持浏览器窗口打开，由用户自行检查并决定是否提交。
- **JavaScript 点击兜底**：在常规点击容易受遮挡或布局影响时，通过浏览器脚本触发点击事件。

## 前置准备

运行脚本前需要：

1. Python 3.x
2. Microsoft Edge
3. Selenium

安装依赖：

```bash
pip install selenium
```

现代版本的 Selenium 通常可以自动管理匹配的 Edge WebDriver。如果运行时出现驱动错误，请先升级 Edge 浏览器；仍然失败时，再手动安装对应版本的 Edge WebDriver 并加入系统环境变量。

## 使用步骤

### 1. 配置目标地址

打开 `auto_fill_edge.py`，将 `main()` 函数中的初始地址替换为目标页面：

```python
url = "xxxxxx"
```

当前脚本还会等待 URL 包含：

```text
A05pjpx/main.aspx
```

如果你的目标系统路径不同，需要同步修改：

```python
wait.until(EC.url_contains("A05pjpx/main.aspx"))
```

### 2. 执行脚本

```bash
python auto_fill_edge.py
```

### 3. 人工登录

脚本会启动 Edge 并打开配置的网址。请在弹出的浏览器窗口中手动完成登录。进入目标页面后，脚本会等待页面中的单选框或下拉菜单加载完成，然后执行预填。

### 4. 复核与提交

脚本结束预填后会提示：

```text
所有选项已尝试设为 A。请检查无误后自行点击提交。
```

请在网页中逐项检查结果。确认无误后再手动提交。回到终端按回车键后，脚本会关闭浏览器并退出。

## 二次开发提示

### 页面选项没有被勾选

可能原因：

- 目标选项的 `value` 并不是 `A`，例如部分系统会使用 `1` 表示优秀。
- 页面使用了 iframe，Selenium 默认无法直接访问 iframe 内部元素。
- 页面是动态渲染的，元素出现后仍需要额外等待。

对应调整方向：

```python
# iframe 示例，具体索引或定位方式需要按页面结构调整
driver.switch_to.frame(0)
```

```python
# value 规则示例
if value and value in {"A", "1"}:
    driver.execute_script("arguments[0].click();", radio)
```

### 下拉菜单匹配不准确

当前逻辑会在选项 `value` 为 `A` 或文本中包含 `A` 时选择该项。如果目标页面使用“优秀”“非常满意”等中文文本，可以按实际字段改为：

```python
if opt.get_attribute("value") == "1" or "优秀" in opt.text:
    s_obj.select_by_index(i)
```
