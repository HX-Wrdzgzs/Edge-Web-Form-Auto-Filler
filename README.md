# Edge Web Form Auto-Filler

这是一个 Edge 浏览器表单辅助脚本，用于在人工确认流程中减少重复填写成本。

## 当前状态

- 维护范围：个人维护。
- 使用范围：学习、测试或明确允许辅助操作的内部流程。
- 文档状态：只保留项目边界和维护说明。
- 许可证状态：暂未选择。

## 项目范围

本工具定位为半自动辅助脚本，不是无人值守工具。

主要原则：

- 人工登录。
- 自动预填。
- 人工复核。
- 人工提交。

## 维护注意事项

- 使用前应确认目标流程允许此类辅助操作。
- 页面结构变化后，选择器和等待条件可能需要调整。
- 不要提交真实账号、Cookie、私有系统地址或运行时数据。
- 不扩展为无人值守批量提交工具。
